Detailed Description

See also
https://github.com/xen-project/xen/blob/master/xen/include/public/arch-x86/hvm/start_info.h

This module manages the PVH boot information, which is passed by the bootloader in ebx when the kernel is loaded using the PVH ELF note (see asm/notes.asm).
