void kmain_start ( const boot_info_t * info)

Starts the kernel. This function should be called once the arch- and/or board-specific initialization code has been executed.

The boot information (command line, initial ramdisk, etc.) must have been recorded with boot_info_set() beforehand (cf. boot.h).
