Builds the initial user stack for a program about to be executed.

The stack is written downward from stack_top.

+-----------------------—+ <- stack_top | strings | +-----------------------—+ <- returned stack pointer | argc | | argv[0..argc-1] | | NULL | | envp[0..] | | NULL | | AT_PAGESZ, page_size | | AT_ENTRY, entry | | AT_NULL, 0 | +-----------------------—+

The returned pointer is 16-byte aligned.

Parameters
stack_topthe top (high address) of the user stack
argcthe number of arguments
argvthe argument list
envpthe environment list
entrythe program entry point
Returns
the initial stack pointer, or 0 on error
