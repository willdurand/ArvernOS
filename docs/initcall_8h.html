Detailed Description

Initcall functions are automatically called when the kernel starts, after the architecture-specific code has booted it.

Use the initcall_*_register() helper functions to register them.

typedef int(*) initcall_t()

This type defines an initcall function, which is a function automatically called when the kernel is started. Use initcall_*_register() helper functions to register them.

void initcall_init ( )

Call the registered initcall functions, in ascending level and priority order, and panics if any of them returns a non-zero value. Called once by kmain_start().
